# エラーロイド ルール正本

このファイルはゲームルールの正本(canonical reference)。`pc-serene-marshmallow.md`(実装計画・進捗ログ)にも同内容の書き起こしがあるが、あちらは経緯込みの作業ログであり、ルールそのものを参照したいときはこちらを見る。カード個別のテキスト・数値は [`cards.md`](./cards.md) を参照。

## 勝利条件

相手の「エラーロイド」(裏面が犯人)カードを先にオープンさせたら勝ち。

## コンポーネント

- アンドロイドカード: 7キャラ、実物カードはいずれも「齋藤さん」の職業違い(探偵/弁護士/美大生/バーテンダー/メイド/マジシャン/猫、カードNo.1〜7)。各キャラにつき「裏がANDOROID版」「裏がERROROID版」の2バリエーションが存在(全28枚、各キャラ4枚)。コード内部の識別子(charlotte/lucas/ivy/ben/lillian/oliver/saint)は開発時のコードネームで、実物カード名とは対応表(下記)でのみ紐付く
- 推理カード: 9種・山札40枚 + リヴィールカード「真相解明」(先攻用1枚コスト13・後攻用1枚コスト12、山札に含まれない別カード)
- 推理力トークン20個、証拠トークン14個(※デジタル版では証拠は無制限カウンター。下記「デジタル版での簡略化」参照)

## 準備〜配置

1. 各プレイヤーに、7キャラ分の「裏ANDOROID版」7枚+「裏ERROROID版」7枚=14枚を配る
2. 先攻/後攻を決め、それぞれ対応する「真相解明」をリヴィールエリアに置く
3. 各プレイヤーは自分の14枚のうち、まず裏ANDOROID版7枚(7キャラ1枚ずつ)を並べる準備をし、そのうち**1キャラだけ**を裏ERROROID版に差し替える。場に並ぶのは7キャラ各1枚(計7枚)、うち1枚だけが真犯人。残り7枚(未使用分)は除外。相手に正体が分からないよう伏せて左からカードナンバー順に並べる
4. 山札から4枚引いて手札にしてゲーム開始(その後ドローで5枚になる)

## ターンの流れ(交互)

相手のエラーロイドがオープンされるまで繰り返す:

1. **ドロー**: 手札が5枚になるまで山札から引く(山札切れ時は廃棄場をシャッフルして山札にする)
2. **インストール**: インストールエリアから推理力を1個、自分のメモリーエリア(上限10個)へ
3. **シンキングタイム**: メモリーエリアの推理力を消費エリアへ移し消費して、以下を好きな順・何度でも実行できる
   - 手札の推理カードを使用(コスト分の推理力を払い公開・効果発動、使用後は廃棄場へ)
   - 自分の場の**未オープン**アンドロイドカードを使用(コスト分の推理力を払いオープンして効果発動)
   - 手元のリヴィールカード「真相解明」を使用(下記「デジタル版での簡略化」参照)
4. **エンド**: 消費エリアの推理力を全てメモリーエリアへ戻し、ターン終了

## 推理力・証拠トークンの循環ルール

- **推理力**: インストールエリア(初期20個)→(インストールで)自分のメモリーエリア→(シンキングタイムの消費で)消費エリア→(エンドフェーズで)自分のメモリーエリアへ全戻し、のクローズドループ。総量20個=プレイヤー2人×メモリーエリア上限10個と一致するため、デジタル版では「インストールエリアの残数」を厳密管理せず、各プレイヤーのメモリーエリアに上限10個のカウンターを持たせるだけで等価に再現している
- **証拠**: 物理コンポーネントは証拠エリアに14個だが、デジタル版では総量制限を設けず、各カードの証拠値を無制限カウンターとして扱う(ユーザー決定済み)。「証拠が足りず効果が発動できない」というルールは存在しない。証拠は0を下回らない

## オープン条件(3パターン)

1. 付与された証拠がアリバイ(体力)以上になった時、即座に(効果発動中でも)強制オープン
2. 一部のカード効果により証拠に関係なく強制オープン
3. 自分のターン中、自分の未オープンカードを自らオープンして効果を使う場合

強制オープン(パターン1・2)時、通常のアンドロイドカードは**カード効果を発動しない**(単に正体が公開されるだけ)。カード効果はパターン3(自分の意志で未オープンカードをコストを払ってオープンする場合)のみ発動する。唯一の例外は**齋藤さん(マジシャン)(コード内部識別子: oliver)**で、相手ターン中に証拠が丁度4になった時だけ専用の常在効果(相手の全アンドロイド証拠+1)が発動する(cards.md参照)。

強制オープンされたカードがエラーロイドだった場合は、原因を問わず即座にゲーム終了。効果は一切発動しない。

## 対象選択の主体と対象範囲

カード効果テキストは「選択の主体(誰が選ぶか)」と「対象の場(どちらの場のカードから選ぶか)」が独立した2軸になっている。

- **「自分」「相手」**(選択する主体): 「自分は」ならカード使用者本人が選ぶ、「相手は」なら対戦相手が(相手自身の意思で)選ぶ
- **対象の場**(カード使用者から見て): 対戦相手の場から選ぶか、自分の場から選ぶか

この2軸は独立しているため、「相手(主体)が、相手自身の場から選ぶ」(=相手に自分の手持ちカードの中から選ばせる)という組み合わせも存在し、書き起こしたカードの大半はこのパターン。**対象の場が「自分の場」になるのは弁護士(旧lucas)の1段目と痕跡発見の2段目の2箇所のみ**(いずれも自分自身の疑い・証拠を自分で調整するステップ)。アイビー(旧ivy)は通常パターン(自分主体+相手の場)であり例外ではない(実物カードで確認済み)。

## 重要なFAQルール

- 発動条件を満たさないカードも使用行動自体は可能(コストを払い、廃棄場へ送る/オープンする)が効果は発動しない。条件を満たす場合は効果発動を拒否できない
- カード効果解決中に他カード効果の割り込みは不可
- 相手に真偽を答えさせる効果(ベン、尋問)で嘘の申告は不可。デジタル版ではサーバーが実際の秘匿状態から機械的に真偽を算出する
- エラーロイドを効果発動のためオープンした場合、効果は発動せずその時点で即座にゲーム終了・敗北確定
- 証拠は0を下回らない

## デジタル版での簡略化・現物ルールとの相違点

現物ルールブック(写真)とデジタル実装が異なる箇所。プレイ中に「あれ、現物カードだとこうだったはず」と混乱しないよう、意図的な相違として明記する。

### リヴィールカード「真相解明」使用後の扱い(現物ルールブックと異なる、確定仕様)

現物ルールブックの写真(13〜14ページ)には「使用したカードは廃棄場へ置いてください。このカードは『証拠回収』で、廃棄場からカードを回収できます」と明記されている。

しかし、デジタル版では**使用後にカードを裏返し、それ以降そのゲーム中は完全に使用不可(廃棄場には送らず、証拠回収による再取得の対象にもならない)**という仕様で確定・実装済み。これは`pc-serene-marshmallow.md`の実装過程で確定された、現物ルールとは異なる意図的な仕様変更。

→ 実物のリヴィールカードで挙動を再確認したい場合は、この一行がその論点の記録。変更する場合は `packages/shared/src/cards/reveal/index.ts` の `RevealCardDef.effect` および `GameEngine.ts` の `useReveal` 処理(`revealCardAvailable` を `false` にするだけで discard していない箇所)を参照。

### 証拠トークンの上限撤廃

現物は証拠トークン14個という物理制約があるが、デジタル版では無制限カウンターとして扱う(前述「推理力・証拠トークンの循環ルール」参照、ユーザー決定済み)。

### 秘匿情報設計: `character` は対戦相手の未オープンカードでも常に公開される

各プレイヤーの場は準備段階でカードナンバー順(①〜⑦)に固定配置されるため、「どの位置にどのキャラがいるか」は両プレイヤーで共通の公開情報であり、そもそも隠す意味がない。**実際に秘匿されるのは各スロットの`identity`(ANDOROID版かERROROID版か)のみ**であり、`character`(キャラクター名)は対戦相手の未オープンカードについても常に見える。

これは`packages/server/src/network/ViewSerializer.ts`の`maskPlayerView`で意図的にそう実装されており、`packages/server/test/network/viewSerializer.test.ts`にも「characterは常に公開(配置順が固定のため)」という専用テストがある。(`pc-serene-marshmallow.md`の秘匿情報設計の説明文が「characterすら伏せる」という逆の記述になっている箇所があるが、これは書き起こし時点の言葉足らずで、実装・テストの方が正しい仕様。)
